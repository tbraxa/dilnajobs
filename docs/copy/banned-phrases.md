# Zakázané fráze a vzory

Nepoužívat v marketingu, UI ani e-mailech.

## AI filler a prázdné claimy
- bez zbytečného šumu / bez šumu
- student demo / preview / SoT v UI
- Bez agenturního šumu / Bez agentur (jako claim)
- Najděte lidi…
- Najděte si…
- ne do kanceláře / ne jen kancelář
- žádný obecný…
- posuňte kariéru / posuňte se vpřed
- práce snů
- na další level
- Airbnb práce / „Airbnb of jobs“ (interní metafora, ne UI)
- revoluční, unikátní, nejlepší na trhu (bez čísla)
- synergie, mindset, talent pool, matching engine

## Niche manufacturing leftover (už neplatí jako brand)
- dílna / výrobní board jako hlavní positioning v claimu
- „jen CNC a svářeči“ jako omezení produktu (produkt je všechny profese)

## Anglicismy a calques
- Remote (v UI vždy „Na dálku“)
- job opening, hiring, onboarding (v UI)
- matching, pipeline (raději: odpovědi, schránka žádostí)
- Get started, Sign up, Apply now (anglické CTA)

## Tech žargon
- MVP, CTA, pokladna v UI copy („Bez pokladny v MVP“)
- Topování (raději: Priorita ve výpisu)
- checksum, token, payload, endpoint
- „něco se pokazilo“ bez dalšího kroku
- anglické systémové hlášky

## Typografie
- em dash (U+2014)
- en dash (U+2013; v marketingových větách; u mezd a rozsahů vždy „až“)

## Povolené náhrady (příklady)
- em/en dash → tečka, čárka, dvojtečka, nebo „až“
- Najděte lidi → Inzerujte pozice / Zveřejněte nabídku
- Get started → Začít / Vystavit nabídku / Založit účet

## Full-product (ne MVP)
- MVP, soft-launch, „zatím jen“, „brzy“ jako výmluva v UI
- SoT, sticky px, viewport, half-screen (meta text v preview)
- CTA „Filtry“ tam, kde patří „Upravit filtry“
## Tools / AEO
- Garantovaná mzda / přesný výpočet daně bez disclaimeru
- „Oficiální výpočet FÚ“ bez zdroje
## Typography / chrome
- Small-caps / drobné uppercase eyebrow labely nad sekcemi (AI balast)
- Tiny ALL CAPS labels jako „O NÁS“, „VÝHODY“, „KATEGORIE“ jako eyebrow

## Poznámky k nasazení

1. Nahradit všechny em dash (—) a en dash (–) v title a UI textu.
2. Meta description na auth stránkách doplnit (dnes chybí).
3. Žádná pole hesla. Po odeslání formuláře ukázat helper_after_send.
4. Po implementaci poslat screenshoty auth + homepage Copy ke kontrole.
